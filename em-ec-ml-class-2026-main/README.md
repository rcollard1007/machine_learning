### Objective

The aim of this course is to:

- Cover the main principles of supervized Machine Learning
- Practice Machine Learning and python coding
- Develop a personal project that can be used by students to expose their ML skills

Evaluation is briefly described in [docs/evaluation.md](doc/evaluation.md).

### Content

- General presentation of enterprise-level ML practices ([docs/guidelines])
- Tutorial material for Machine Learning, with Regression and Classification tasks, using tree-based methods ([notebooks])
- A reusable project demo ([src/eclyon/demo.py])

## How to use it

### Prerequisites

- Download [Train.zip](https://www.kaggle.com/c/bluebook-for-bulldozers/data) from the [bluebook for bulldozers  competition](https://www.kaggle.com/c/bluebook-for-bulldozers/overview), unzip it in the folder `data`.
- Install `Graphviz` (see [graphviz](https://forum.graphviz.org/t/new-simplified-installation-procedure-on-windows/224#abbreviated-installation-instructions-recommended-for-users-with-installation-experience) and the [source files](https://graphviz.org/download/)).
- Have [uv](https://docs.astral.sh/uv/getting-started/installation/) installed on your machine.

### Setup

Install the project

```sh
uv sync
```

This creates a new virtual environment at `.venv`, install a project-specific python executable whose version is set in `.python-version`, and install the project dependencies declared in `uv.lock` (which is programatically generated by uv from `pyproject.toml`). This command is idempotent, e.g. running it a second time does nothing.

### Usage

[Activate](https://docs.astral.sh/uv/pip/environments/#using-a-virtual-environment) the virtual environment.

Launch a jupyter server

```sh
jupyter notebook
```

Run the demo webui from the repo root

```sh
eclyon webui --config-path conf/webui.yaml
```
